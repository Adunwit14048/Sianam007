# แนะนำตัวเอง

**ชื่อ - นามสกุล:** นายอดุลวิทย์ เกตุษา

**ชื่อเล่น:** น้ำ

**อายุ:** 18 ปี

**วันเกิด:** 15/ศ.ค./2551

**งานอดิเรก:** ดูซีรีย์ ฟังเพลง เล่นเกม

**อาชีพในฝัน:** เปิดร้านขายและซ่อมคอมพิวเตอร์ ไมค์ ทำ Creators และ Influencers

**สัตว์เลี้ยงที่ชอบ:** หนูแฮมเตอร์ แมว หมา

**วงไอดอลที่ชอบ:** BNK48 CGM48 AKB48

**ศิลปินที่ชอบ:** นนท์ ธนนท์ เดอะทอย นุนิว ดาเอ็นโดรฟิน

**เพลงที่ชอบฟัง:** 9นาฬกา มีสิทธิอะไร เสียงเพลงในใจฉัน ขอโทษได้ไหม

**ดารานักแสดงที่ชอบ:** พันธ์รักแมว แซนดี้ แดนซ์ เจมีไนน์ วินเมธวิน เดตะวัน น้ำหนึ่ง
